# P3：真机联调修复 + 知识库 AI 问答

P3 分两部分：前半是把 P1/P2 的流程放到真实抖音页面上跑，修掉只有真机才暴露的问题；后半是按用户要求在控制台知识库页加一个「问知识库」的 AI 对话。

## 一、真机联调修复（2026-11-13 15:59–16:12）

用户已在收藏夹「有帮助」里放了 3 条作品。第一次手动同步立刻失败，随后逐步修到全链路跑通。

| # | 问题 | 根因 | 修法 | 备份 |
|---|---|---|---|---|
| 1 | 「无法可靠确认已进入收藏夹」 | 「有帮助」节点没有 `aria-selected/aria-current/active`，`SELECTED_JS` 恒为 false；收藏夹列表异步渲染 2–4 秒 | 新增 `ENTERED_JS`（「返回」+「添加视频」同时存在）+ `HAS_LABEL_JS` + `_wait()` 轮询，`SELECTED_JS` 保留做并集 | `.p3-backups\20261113-155932` |
| 2 | 误收 10 条（实际 3 条） | `collect()` 把侧栏纯文字推荐链接也当成卡片；标题带点赞数前缀 | 要求「有封面 img 且卡片高 ≥ 60」，标题剥掉 `7938 `/`1.2万 ` 前缀 | 同上 |
| 3 | 转写双双失败但钱已花 | 妙记刚创建未就绪时 `minutes +detail` 退出码 1、stdout 仍是合法 JSON 且无顶层 error；旧代码一律当硬错误 | `_run_lark(allow_item_failure=…)` 只在 `ok` 非 false 且无 error 时降级，非终态错误继续轮询，`status=failed/error` 才终止 | `.p3-backups\20261113-160538` |

## 二、知识库 AI 问答（2026-11-13 16:30–17:17）

用户要求：知识库页面加一个 AI 对话框，用来搜索和询问；「这个 AI 要清楚知道这个项目，且自己在知识库中」。

### 设计取舍

- **不做向量检索**：`kb.search()` 是 SQLite 子串检索，对这个规模（几十到几百篇）够用，且新增依赖和索引成本不划算。
- **检索顺序**：整句搜索 → 按标点切词后逐关键词搜索 → 都没有就回退最近入库的 3 篇。
- **上下文控制**：最多 3 篇、每篇正文截断 3000 字，避免一次问答烧掉大量 token。
- **双用途提示词**：system prompt 里既有「这个程序怎么工作」（04:00 扫描、五步流程、重试不重复计费、AUTO 区块保护、目录结构、每日 AI 上限），也有「只依据参考笔记回答，查不到就说不知道」。所以它既能回答视频内容，也能回答「这个程序每天几点运行」。
- **空库短路**：知识库为空时直接返回提示，不调用 AI、不计费。

### 后端

- `app/chat.py`（新增）：`NOTE_LIMIT=3`、`NOTE_CHARS=3000`、`QUESTION_MAX=500`、`OVERVIEW_TOPICS=30`、`KEYWORD_LIMIT=6`；`_plain()` 去 frontmatter 与 HTML 注释；`keywords()`、`select_notes()`、`_overview()`、`build_messages()`、`answer()`。
- `app/enrich.py`（改造）：`_content(raw)` 返回 `(正文, tokens)`、`_extract(response)` 解析成 JSON 对象；新增 `Enricher.chat(config, messages)`，共用 `_ask` 重试与 `work/ai_usage.json` 台账（超限抛「今日 AI 调用已达上限，明天继续」）。
- `app/server.py`（改造）：`POST /api/chat` → `knowledge_answer(config, question)`；`RuntimeError` 的 502 白名单加入该路由。

### 前端

- 知识库页标题栏加「问知识库」按钮（`aria-pressed` 同步）。
- 打开后 `.kb-layout` 变三列：正文 `minmax(0,1fr)` + 问答 `380px`，目录列收起（否则正文只剩 ~240px）。`@media(max-width:1180px)` 下自动改单列、问答卡片置底。
- 问答区：问题输入（`maxlength=500`）、回答卡片（走既有的安全 Markdown 渲染，不拼 HTML）、来源笔记按钮（点击在左侧打开原文）、清空；`Ctrl/Cmd+Enter` 发送。
- 正文为空时提示随面板状态切换（打开：「在右侧提问 / 点答案里的笔记来源…」）。

### 修掉的两个真机 bug

1. **Obsidian 打开链接失效**（`app/knowledge.py`）：`urlencode` 默认 `quote_plus` 把路径空格编成 `+`，Obsidian 不还原 → 改 `quote_via=quote`（`%20`）。
2. **「问知识库」点开无反应**（`app/index.html`）：`chatToggle` 里 `!panel.hidden` 把 show 恒置 false → 改 `panel.hidden`。

## 六、已知限制

- 回答质量取决于检索命中：问题与笔记用词差异大时可能找不到相关笔记（会回退最近 3 篇），此时答案可能偏泛。
- 每次问答消耗 1 次 AI 额度，与 AI 加工共用每日上限（默认 200）。
- 不带对话记忆：每条问题独立，不继承上一轮上下文。
- 界面视觉参考 Unslop 方法（Damir Sokolovsky @heydamir，CC BY 4.0），详见 `app/index.html` 顶部注释。
