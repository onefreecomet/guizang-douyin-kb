# P1：自动流水线与原文知识库

本期实现：收藏夹「有帮助」增量扫描 → 按视频 ID 去重 → 下载校验 → 飞书妙记转写/断点恢复 → Obsidian 原文笔记。六页控制台保留手动下载与文件管理，新增自动同步、任务队列、知识库和设置。

## 运行

桌面快捷方式继续启动实际运行目录。服务必须保持运行，关闭浏览器页面不会停止服务，点击「退出服务」会停止调度。未配置 Windows 开机启动。

- 控制台： http://127.0.0.1:8765/
- 调度：北京时间每日04:00；白天无周期性扫描。首次安装当天不补跑；已有服务错过当天04:00，在恢复服务后补一次。暂停/人工验证状态不自行补跑。
- 手动触发：「立即同步」；「暂停」保存检查点并清理相应子进程，「继续」从未完成任务开始，再检查新增。
- 登录/验证码：弹出 Edge 人工完成，180秒窗口内可继续；超时后保留待人工状态，处理后点继续。

## 配置与状态

运行目录 work/config.json 保存配置；API只返回 ai_key_set，不回显 API 密钥。首次无此文件时用默认配置；设置保存后原子写入。首期固定收藏夹、04:00和90目录，路径和通知可配置。

- work/pipeline.db：队列及调度检查点，不能作为缓存删除。
- work/knowledge.db：可删除后重建的全文索引，Markdown为知识来源。
- work/last_job.json 与各视频 task_state.json：沿用下载/转写恢复记录，不要覆盖。
- 飞书接收人需在设置填写 open_id 或 chat_id，保存后点「发送测试通知」。留空时首页明确提示未配置；不会声称通知已发送。
- AI配置仅预留；P1不调用AI。摘要、自动主题/系列及总索引页生成留P2。

## 笔记保护

仅写入用户指定vault的「90 - 抖音精选/素材/YYYY-MM/」。笔记含来源、作者（未知留空）、关键词、时长、带时间戳原文、本地视频链接及「我的笔记」。视频不复制到vault。

按video_id找到已有笔记，保留其位置和名称；仅更新程序拥有的frontmatter字段及AUTO标记内正文。用户字段、标记外笔记保留。`status: 已定稿` 或 `status: 冻结` 完整跳过；P1不修改主题/系列文件和已有列表。损坏AUTO/frontmatter拒写。跨进程锁、同目录临时文件与原子替换避免并发覆盖；拒绝路径遍历、symlink/junction越界。控制台Markdown使用DOM文本渲染，不解释原始HTML。

## 转写与费用边界

已下载不等于已入库；旧资料仍会检测转写和发布。已有转写原文可本地合并，不发起远端请求。已有file/minute token复用。远端转写间隔45秒，限流暂停整个自动队列。

创建妙记前先记录minute_creation_pending；如超时或中断，没有minute token且pending仍在，结果未知，禁止自动重新创建。请先在飞书核对，在下载页明确确认重建才可再次请求。无法承诺远端API与本地落盘之间绝对不会有不确定状态；本期采取保守拒绝自动重复计费。

## 验证

使用实际运行目录虚拟环境，在项目根执行 `python -m unittest discover -s tests`。覆盖离线模拟服务、真实本机HTTP、临时vault/SQLite、并发发布、真实Windows进程树与Node DOM样例。真实抖音扫描/下载、真实付费转写、实际飞书消息发送需要单独验收，不能用离线结果替代。
